# Assessment catalogue content

All seeded versions begin as Draft. These are starting assessments for technical authors to review against their actual role requirements, rather than claims of validated hiring benchmarks. Do not edit the definition of an assigned/published version; add a new version for future changes.

- Java Full Stack with Angular: Java collections/concurrency, HTTP request cancellation, reactive forms, RxJS request ordering, authorization boundaries, a Java duplicate-ID coding task, and two full-stack scenarios. Java execution reuses the existing isolated runner and six reference tests.
- React Developer: immutable state, stable list keys, Effect dependencies/cleanup, functional state updates, accessibility, server authorization, request states; three written scenarios covering races, large editable lists and checkout workflows. No coding question.
- Cloud Operations Developer: Kubernetes probes, IAM least privilege, CloudWatch alarms, backup verification and incident response; three written scenarios covering deployment incidents, probe configuration and RPO/RTO recovery. No coding question.

Written rubrics provide point ranges, expected reasoning and trade-offs. Supporting notes are optional. All versions have 11 questions, a 60-minute shared timer and 100 available points.
